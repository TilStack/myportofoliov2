# Polices auto-hébergées

- **Inter** (variable) et **Poppins** (400, 500, 600, 700, 900), sous-ensemble latin, récupérées depuis
  Google Fonts. Licence SIL Open Font License 1.1 (https://openfontlicense.org).
- Les noms de fichiers portent la version de Google Fonts (`inter-v20`, `poppins-v24`) : le cache est
  `immutable` un an (firebase.json), donc **changer le nom** de tout fichier remplacé.
